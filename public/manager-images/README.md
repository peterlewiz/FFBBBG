# Custom manager images

Drop an image in this folder named exactly `<userId>.jpg` (or `.png` /
`.webp`) to use it as that manager's full-bleed hero image in the
homepage headlines. No code changes needed - the site checks for a file
here first and falls back automatically to a generated neon placeholder
if one isn't there.

Each manager also has a signature neon color, defined in
[`src/lib/teamColors.ts`](../../src/lib/teamColors.ts) and used across
the whole site (power rankings, charts, head-to-head, badges). If you
supply custom art, matching that color keeps everything coherent.

The current placeholders are generated by
[`scripts/generate_filler_images.py`](../../scripts/generate_filler_images.py)
(`python3 scripts/generate_filler_images.py`) - wide 1260x480 cards
sized for the hero banner's aspect ratio. Real art should use roughly
the same proportions.
