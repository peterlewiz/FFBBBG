# Custom manager images

Drop an image in this folder named exactly `<userId>.jpg` (or `.png` /
`.webp`) to use it instead of that manager's Sleeper avatar in the
homepage headlines (and anywhere else `ManagerImage` gets used later).
No code changes needed - the site checks for a file here first and
falls back automatically (custom image → Sleeper avatar → generic icon)
if one isn't there yet.
